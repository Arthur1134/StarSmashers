# Star Smashers Survival

HTML5 top-down survival shooter — waves, XP level-ups, timed bosses, ship select, meta store, and achievements.

## Play

Open `index.html` in a modern browser, or play the GitHub Pages build when enabled.

## Version / updates

- `GAME_VERSION` in `index.html` and `version.json` should match each release.
- Hosted builds check `version.json` on the menu and offer Reload if a newer version is published.
